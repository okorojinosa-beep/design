# Field photos

Real photographs from real completed jobs. This folder is the highest-value thing in the repo: it is the only route that gets photography into an unattended render.

**Naming:** `<pillar>-<what>-<nn>.jpg` — `rescue-lagos-asaba-01.jpg`, `refuel-meter-estate-02.jpg`. Lowercase, hyphens, no spaces.

**Size:** long edge 1600px is plenty, under ~800KB each. Panels render at about 470x560.

**What earns its place** — a named route with the actual vehicle on the actual bed; a meter mid-delivery; a hydrometer in a diesel jar; hands doing the work; a dashboard with real numbers on it. Never a stock photo, and never a generated image under a caption that claims a specific real job.

**Reference them** from a spec as `assets/field-photos/<file>` or by raw URL.

The Route Report — a real driver photo with a named route — is the strongest asset the account has ever had, and it has been dark since 13 August 2026.
